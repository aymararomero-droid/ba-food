BA FOOD — Proyecto integrador de página web

ARCHIVOS
- index.html: estructura y contenido de la página.
- styles.css: diseño visual, colores, tipografías, efectos hover y responsive.
- script.js: buscador, filtros, favoritos, modo oscuro, menú móvil y validación del formulario.

CÓMO PROBARLA
1. Descomprimí el archivo ZIP.
2. Abrí la carpeta en Visual Studio Code.
3. Abrí index.html en el navegador (o usá la extensión Live Server).
4. Probá el buscador, los filtros, los corazones de favoritos, el modo oscuro y el formulario.

CÓMO PUBLICARLA EN GITHUB PAGES
1. Creá un repositorio público en GitHub, por ejemplo: ba-food.
2. Subí index.html, styles.css y script.js (también podés subir README.txt).
3. Entrá a Settings > Pages.
4. En Build and deployment, elegí Deploy from a branch.
5. Seleccioná la rama main y la carpeta / (root), y guardá.
6. Esperá a que GitHub genere el enlace de la página.

IMPORTANTE
- Las fotografías se cargan desde Unsplash; para verlas se necesita conexión a internet.
- Los enlaces "Ver mapa" abren una búsqueda de cada restaurante en Google Maps.
- El formulario es una demostración: valida los datos y muestra un mensaje, pero no envía correos.
- Los restaurantes y domicilios se incluyeron como ejemplos de la guía. Verificá dirección, horarios y disponibilidad antes de visitar.
- La guía no publica precios porque pueden cambiar.
